# GTA VI — Leonida fan experience

Откройте **index.html** через **Open with Live Server** в VS Code. Сборка, npm, регистрация и backend не нужны. Все изображения используются из корня проекта без изменений. Нужен современный браузер с Canvas 2D и ES modules.

## Три части

- Адаптивный сайт: hero, описание мира, персонажи, галерея с увеличением, анимации и кнопки запуска.
- Загрузка длительностью не менее 11 секунд: пять артов, переходы, подсказки, проценты. Запуск ждёт декодирования ресурсов и генерации карты; при ошибке доступен возврат.
- Оригинальная аркадная Canvas-игра: город 3600 × 3000, пляж и море, парки, здания, пальмы, трафик, 100 пешеходов, четыре типа машин, стрельба, полиция и три миссии.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | Пешком: движение. В машине: W газ, S тормоз/задний ход, A/D поворот |
| Shift | Бег |
| E | Сесть в ближайшую машину / выйти на малой скорости |
| Пробел | Ручной тормоз |
| Мышь / ЛКМ | Прицел / выстрел |
| 1 / 2 | Пистолет / автомат |
| R | Перезарядить |
| Esc | Пауза |

Рядом со стартом стоит розовый спорткар. Следуйте розовому маркеру и стрелке у края экрана. First Ride — поездка к маркеру, Delivery — забрать и доставить посылку, Escape — скрыться от полиции и приехать в безопасную зону. Награды: $500, $1000, $1500. После миссий доступен свободный режим.

Розыск растёт от стрельбы, угона и столкновений. Разрывайте прямую видимость и увеличивайте дистанцию: после нескольких секунд укрытия звёзды убывают. Зелёный маркер клиники восстанавливает здоровье и запас патронов. При нуле здоровья используйте Restart. Меню позволяет продолжить, перезапустить и выйти; повторный запуск создаёт новую игру.

Звук включается кнопкой SOUND: синтезированные выстрелы, двигатель и сигналы. На мобильных адаптирован сайт; для игры необходимы клавиатура и мышь.

## Файлы

- `index.html`, `styles.css` — сайт и интерфейсы.
- `js/app.js` — галерея, переходы, загрузка ресурсов.
- `js/world.js` — детерминированная карта и столкновения.
- `js/game.js` — игровой цикл, ввод, физика, NPC, розыск, задания.
- `js/render.js` — графика Canvas, камера, мини-карта.
- `js/audio.js` — Web Audio.

Это независимый фанатский проект, не официальная игра GTA VI. Логика полиции, трафика и физика намеренно аркадные. Прогресс живёт в текущем запуске и не сохраняется после перезагрузки.

## Проверка

`node --test tests/game.test.mjs` — 11 тестов симуляции: движение, стены, транспорт, стрельба, перезарядка, задания, розыск, клиника, пауза, рендер и перезапуск после потери здоровья. Canvas и DOM в этих тестах заменены тестовыми объектами; визуальная проверка выполнялась отдельно в Chrome.

Для запуска без расширения Live Server можно использовать `node dev-server.cjs` и открыть `http://127.0.0.1:4173`. Это только необязательный локальный файловый сервер для разработки, не backend игры.
